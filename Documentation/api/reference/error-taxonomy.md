# Error Taxonomy

WeatherWear uses a shared JSON error model for application-level exceptions handled by `GlobalExceptionHandler`.

## Error Response Shape

```json
{
  "timestamp": "2026-04-30T12:45:00",
  "status": 400,
  "error": "Bad Request",
  "message": "email: Email must be valid",
  "path": "/api/auth/register"
}
```

| Field | Meaning |
| --- | --- |
| `timestamp` | Server-side timestamp when the error response was produced |
| `status` | HTTP status code |
| `error` | HTTP reason phrase |
| `message` | Human-readable error details |
| `path` | Request URI |

## Status Codes

| HTTP status | Category | Typical source | Recovery guidance |
| --- | --- | --- | --- |
| `400 Bad Request` | Validation | Missing field, invalid enum, invalid coordinate range, malformed JSON | Fix request body or query parameters |
| `401 Unauthorized` | Authentication | Missing token, invalid credentials, expired or invalid JWT | Log in again and resend `Authorization: Bearer <token>` |
| `403 Forbidden` | Authorization | Authenticated user lacks permission | Use an account with the required role or avoid restricted operation |
| `404 Not Found` | Ownership or missing resource | History, feedback, or chat session not found for current user | Check the resource ID and current account |
| `409 Conflict` | Data conflict | Duplicate email, database integrity conflict | Use another unique value or retry after resolving conflict |
| `502 Bad Gateway` | Upstream dependency | OpenWeather API or LLM provider failure | Retry later, check external API keys and provider availability |
| `500 Internal Server Error` | Unexpected backend issue | Unhandled exception | Check server logs and create a defect ticket |

## Validation Messages

Examples of validation messages generated by Jakarta Bean Validation:

| Scenario | Message |
| --- | --- |
| Registration email missing | `email: Email is required` |
| Registration email invalid | `email: Email must be valid` |
| Password too short | `password: Password must be at least 6 characters` |
| City query missing | `city parameter is required` |
| City too long | `getWeatherByCity.city: City must be at most 120 characters` |
| Latitude out of range | `getWeatherByCoordinates.lat: Latitude must be greater than or equal to -90` |
| Recommendation location missing | `hasLocation: City or both latitude and longitude are required` |
| Feedback has no content | `hasFeedbackContent: Rating or comment is required` |
| Chat message blank | `message: Message is required` |

## Security Error Note

Most application errors are returned as `ErrorResponse`. Invalid JWT tokens are rejected inside `JwtAuthFilter` with HTTP `401` and the message `Invalid or expired JWT token`. Depending on Spring Security handling, that response may be produced before the global exception handler formats the body.
